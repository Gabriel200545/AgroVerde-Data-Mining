# Diccionario de Datos

| Campo | Tipo de Dato | Descripción | Unidad | Ejemplo |
|---|---|---|---|---|
| `id_lote` | String | Identificador único del lote agrícola | N/A | `LOTE-012` |
| `fecha` | Date | Fecha del registro de cosecha o lectura | YYYY-MM-DD | `2026-03-15` |
| `tipo_cultivo` | String | Tipo o variedad de cultivo | N/A | `Aguacate Hass` |
| `rendimiento_ton_ha` | Float | Rendimiento obtenido por hectárea | Ton/Ha | `14.5` |
| `volumen_agua_m3` | Float | Volumen de riego consumido | m3 | `1250.0` |
| `porcentaje_perdida` | Float | Porcentaje de pérdida registrado | % | `4.2` |
| `produccion_total_ton` | Float | Toneladas totales cosechadas | Ton | `145.0` |
